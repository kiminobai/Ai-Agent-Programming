# AI Agent 开发工程师学习路线（60天）

## 目标

从 Web 全栈开发工程师转向 AI Agent 应用开发工程师。

适合技术背景： - React - Python - FastAPI - 全栈项目开发经验

------------------------------------------------------------------------

# 学习路线总览

  --------------------------------------------------------------------------------------------------------------
  阶段        时间        学习方向      核心知识                               阶段任务          输出成果
  ----------- ----------- ------------- -------------------------------------- ----------------- ---------------
  第1阶段     1-5天       LLM基础       Token、Embedding、API调用、Streaming   实现AI聊天应用    AI Chat Demo

  第2阶段     6-10天      Prompt工程    System Prompt、Few Shot、ReAct         编写Agent提示词   Prompt模板库

  第3阶段     11-20天     Tool Calling  Function Calling、API工具              开发AI助手        第一个Agent

  第4阶段     21-35天     LangChain     Chain、Agent、Tool、Memory             构建业务Agent     LangChain项目

  第5阶段     36-45天     RAG知识库     文档解析、Embedding、向量数据库        企业知识库助手    RAG Agent

  第6阶段     46-55天     LangGraph     State、Node、Edge、Workflow            多步骤Agent       工作流Agent

  第7阶段     56-60天     Multi-Agent   Agent协作、角色分工                    AI团队助手        多Agent系统

  第8阶段     持续提升    工程部署      FastAPI、Docker、Redis、Linux          生产部署          企业级项目
  --------------------------------------------------------------------------------------------------------------
